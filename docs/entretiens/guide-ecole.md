# Guide d'entretien : service carrière (P0 repérage, P8 démonstration)

Durée : 45 minutes. Interlocuteur visé : responsable du service carrière ou des relations entreprises.

## Objectifs
1. Comprendre ce que le service fait aujourd'hui pour l'orientation stages / césure, avec quels outils et quel budget.
2. Savoir quelles données l'école détient réellement, sous quelle forme et avec quelle base légale.
3. Tester l'intention de partager ces données et de payer pour EdGraph.

## Trame
1. **Organisation** : taille de l'équipe, nombre d'étudiants suivis, moments clés de l'année.
2. **Outils actuels** : JobTeaser ou autre ? Pour quoi faire ? Ce qui marche, ce qui manque.
3. **Données détenues** : enquêtes d'insertion, historique des stages et conventions, annuaire alumni, catalogue de cours. Format, mise à jour, qui les possède (école, association d'alumni) ?
4. **Cadre** : base légale de ces données, possibilité de les traiter par un prestataire, délégué à la protection des données.
5. **Démonstration (P8 seulement)** : Q1–Q4 sur données publiques, Q5–Q6 sur données synthétiques (le dire explicitement).
6. **Intention** : seriez-vous prêts à fournir vos données pour un pilote ? Qui décide ? Quel ordre de grandeur de budget pour ce type d'outil ? Quel calendrier d'achat ?

## Compte rendu (`docs/entretiens-ecoles/<ecole>.md`)
- Outils et budget actuels
- Données disponibles (tableau : donnée, format, propriétaire, base légale)
- Intention de partage (oui / non / conditions)
- Intention d'achat (oui / non / conditions, budget évoqué)
- Prochaine étape
