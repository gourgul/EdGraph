# ADR-0003 : modèle économique, équipe et calendrier du POC

Date : 24/11/2026
Statut : accepté

## Décisions
- **Modèle économique (D2)** : pas de revenu pendant le POC. À terme, produit vendu aux écoles (service carrière). Hypothèse à valider en P8 (volet école).
- **Équipe (D3)** : Louis et Jules codent tous les deux, avec Claude Code. Chacun porte des modules entiers. Proposition : Louis sur ontologie, pivot et graphe ; Jules sur les sources marché du travail / entreprises / salaires, les fiches sources et le protocole de test ; les deux sur l'annotation (P4).
- **Calendrier (D4)** : test utilisateurs fin avril 2027. Jalons : P0–P1 fin décembre 2026 · P2–P3 mi-février · P4–P5 mi-mars · P6–P7 mi-avril · P8 fin avril.

## Alternatives écartées
- Test avant mi-mars 2027 : choisi quand la cible était Parcoursup, trop serré pour deux temps pleins.
- Juin 2027 : étudiants moins disponibles.

## Conséquences
- Temps disponible = ressource rare : périmètre minimal à chaque phase, tout le reste en backlog.
- Jules monte en compétence en développement : issues bien bornées au début, PR expliquées en langage simple.
- Préalable : vérifier les règles d'activités extérieures chez EY et RBC (D12) avant tout lancement public.
